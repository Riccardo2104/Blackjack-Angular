# Progetto angular
In questo progetto realizzerò un spa dove al interno verrà similato un versione minificata del gioco del blackjack, 
usando l'api https://deckofcardsapi.com/.
## Meccaniche del gioco:
 - Pescare una carta
   - Il dealer dovrà poter pescare una carta
 - Chiamare carta
   - Il giocatore e il dealer dovranno poter chiamare carta
 - Mischiare il mazzo
   - Dopo che sono state giocate(per velocità) 3 turni verranno mischiate le carte.
